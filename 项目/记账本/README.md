# 记账本应用

一个简单易用的个人记账管理工具，使用 Python 和 Tkinter 开发，帮助您轻松记录和管理日常收支。

## 功能特性

**添加账单**：记录收入和支出，自动记录时间
**账目清单**：以表格形式清晰展示所有账单记录
**统计功能**：自动计算总收入、总支出和结余
**删除记录**：支持删除选中的账单记录
**数据持久化**：数据保存在本地 `data.txt` 文件中（JSON 格式）

## 运行要求

- Python 3.x
- tkinter（Python 标准库，通常已包含）

## 安装与运行

1. 克隆或下载此仓库
2. 确保已安装 Python 3
3. 运行程序：

```bash
python 记账本.py
```

## 使用方法

1. **添加账单**：
   - 在"请输入帐单项目"输入框中输入项目名称（如：买菜、工资等）
   - 在"请输入帐单金额"输入框中输入金额
   - 选择"收入"或"支出"分类
   - 点击"确认提交"按钮

2. **查看统计**：
   - 程序会自动在顶部显示总收入、总支出和结余信息

3. **删除记录**：
   - 在账目清单表格中点击选中要删除的记录
   - 点击"删除选中"按钮
   - 确认删除操作

## 数据存储

所有账单数据保存在 `data.txt` 文件中，使用 JSON 格式存储。数据结构如下：

```json
[
  {
    "时间": "2022/05/07 14:20:21",
    "项目": "收到货款",
    "金额": 20000,
    "分类": "收入"
  }
]
```

### 主要函数

- `readData()`：从 `data.txt` 读取数据
- `writeData(dataList)`：将数据写入 `data.txt`
- `addData(content, amount, cla)`：添加新的账单记录
- `deleteData(index)`：删除指定索引的账单记录
- `sumin()`：计算总收入
- `sumout()`：计算总支出
- `showData()`：格式化显示数据

## 注意事项

- 首次运行前，请确保 `data.txt` 文件存在且包含有效的 JSON 数组格式（即使是空数组 `[]`）
- 删除操作不可撤销，请谨慎操作
- 数据文件 `data.txt` 请妥善保管，避免误删
