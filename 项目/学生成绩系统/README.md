# 学生成绩管理系统

一个基于 Python Tkinter 开发的学生成绩管理系统，支持学生信息的录入、查询、修改和删除功能。

## 📋 项目简介

本项目是一个桌面应用程序，用于管理学生的成绩信息。系统采用图形化界面，操作简单直观，支持对学生姓名、语文、数学、英语三门课程成绩的完整管理。

## ✨ 功能特性

- 🔐 **用户登录**：安全的登录验证机制
- 📝 **成绩录入**：添加新学生的成绩信息
- 🔍 **成绩查询**：按姓名查询学生成绩，支持表格展示
- ✏️ **成绩修改**：根据姓名查询并修改学生成绩
- 🗑️ **成绩删除**：根据姓名删除学生记录
- 📊 **数据展示**：使用 Treeview 表格组件展示所有学生数据
- 🔄 **数据刷新**：实时刷新数据列表

## 🛠️ 技术栈

- **Python 3.x**
- **Tkinter**：GUI 界面开发
- **ttk**：现代化主题组件
- **JSON**：数据存储格式

## 🚀 快速开始

### 环境要求

- Python 3.6 或更高版本
- Tkinter（Python 标准库，通常已包含）

### 安装步骤

1. **克隆或下载项目**
   ```bash
   git clone https://github.com/fangyi-code/My_University_Work.git
   cd 学生成绩系统
   ```

2. **检查 Python 版本**
   ```bash
   python --version
   ```

3. **运行程序**
   ```bash
   python LoginPage.py
   ```

## 📖 使用说明

### 登录系统

1. 启动程序后，会显示登录界面
2. 默认账号：`admin`
3. 默认密码：`123456`
4. 点击"登陆"按钮进入系统

### 功能操作

#### 1. 录入成绩
- 点击菜单栏"录入"
- 填写学生姓名、数学、语文、英语成绩
- 点击"录入"按钮保存数据

#### 2. 查询成绩
- 点击菜单栏"查询"
- 系统会以表格形式展示所有学生成绩
- 点击"刷新数据"按钮可更新数据列表

#### 3. 修改成绩
- 点击菜单栏"修改"
- 输入要修改的学生姓名
- 点击"查询"按钮查找学生
- 修改成绩后点击"修改"按钮保存

#### 4. 删除成绩
- 点击菜单栏"删除"
- 输入要删除的学生姓名
- 点击"删除"按钮确认删除

#### 5. 关于
- 点击菜单栏"关于"
- 查看项目信息和作者信息

## 🔧 代码结构说明

### LoginPage.py
- `LoginPage` 类：登录页面主类
- `login()` 方法：处理用户登录验证

### MainPage.py
- `MianPage` 类：主页面类
- `create_page()` 方法：创建菜单栏和各个功能页面
- `show_xxx()` 方法：切换不同功能页面

### views.py
包含以下视图组件类：
- `InsertFrame`：成绩录入页面
- `SearchFrame`：成绩查询页面（带表格展示）
- `ChangeFrame`：成绩修改页面
- `DeleteFrame`：成绩删除页面
- `AboutFrame`：关于页面

### db.py
数据访问层，提供以下方法：
- `check_login(username, password)`：验证用户登录
- `all()`：获取所有学生数据
- `insert(student)`：添加新学生
- `search_by_username(name)`：按姓名查询学生
- `update(stu)`：更新学生信息
- `delete_by_username(name)`：按姓名删除学生

## ⚠️ 注意事项

1. **数据持久化**：当前版本数据存储在 JSON 文件中，程序重启后数据会保留
2. **数据备份**：建议定期备份 `students.json` 文件
3. **macOS 菜单栏**：在 macOS 系统上，菜单栏可能显示在系统顶部菜单栏而非窗口内

## 🐛 已知问题

- 在 macOS 系统上，菜单栏可能不显示在窗口内（显示在系统菜单栏）
- 数据修改后需要手动刷新查询页面才能看到最新数据
