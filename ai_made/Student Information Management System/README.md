# 🎓 学生信息管理系统

一个功能完善的学生信息管理系统，支持图形界面操作和自然语言交互，具备数据统计分析、机器学习预测等高级功能。

## ✨ 主要特性

### 📋 核心功能
- **学生信息管理**：添加、修改、删除、查询学生信息
- **多条件查询**：支持按班级、年龄范围、性别等条件组合查询
- **数据持久化**：自动保存到 JSON 文件，数据安全可靠

### 🤖 智能交互
- **自然语言处理**：支持中文自然语言指令输入
- **上下文对话**：支持多轮对话，可基于上一次查询结果进行后续操作
- **智能提示**：友好的用户提示和错误信息

### 📊 统计分析
- **统计报告**：自动生成班级分布、性别分布、年龄统计等报告
- **条件统计**：按指定条件统计学生人数

### 🔮 机器学习
- **班级预测**：基于朴素贝叶斯算法，根据年龄和性别预测学生最可能所属的班级

## 🚀 快速开始

## 📖 使用指南

### 界面操作

#### 1. 添加学生
点击 **➕ 添加学生** 按钮，填写以下信息：
- 学号（必填，唯一）
- 姓名（必填）
- 年龄（10-22岁）
- 性别（男/女）
- 班级（如：一班、二班、1班等）
- 电话（11位手机号，以1开头）

#### 2. 修改学生
点击 **✏️ 修改学生** 按钮：
1. 输入学号并点击"查询"
2. 修改需要更新的字段（班级、电话、年龄、性别）
3. 点击"更新"保存

#### 3. 删除学生
点击 **🗑️ 删除学生** 按钮：
1. 输入学号
2. 确认删除操作

#### 4. 查询学生
点击 **🔍 查询学生** 按钮，支持两种查询方式：
- **精确查询**：按学号精确查找
- **条件查询**：按班级、年龄范围、性别等条件组合查询

#### 5. 统计报告
点击 **📊 统计报告** 按钮，查看：
- 总学生人数
- 各班级人数及占比
- 性别分布
- 年龄统计（平均、最小、最大）
- 人数最多的班级

#### 6. 班级预测
点击 **🤖 预测班级** 按钮：
1. 输入年龄和性别
2. 系统将基于历史数据预测最可能的班级
3. 显示预测结果和置信度

### 自然语言交互

在顶部的 **自然语言输入框** 中输入中文指令，系统会自动解析并执行。

#### 添加学生示例
```
添加学生李四，学号2023001，年龄18，男生，一班，电话13812345678
新增学生张三，学号2023002，19岁，女，二班，手机号13912345678
```

#### 修改学生示例
```
把学号2023001的班级改成二班
修改学号2023002的电话为13987654321
```

#### 查询学生示例
```
查询学号2023001
查找二班的学生
查询年龄在18-20岁之间的学生
搜索二班年龄在18-20岁之间的女生
```

#### 统计示例
```
统计各班级人数
查询二班年龄在18-20岁之间的女生有多少人？
```

#### 上下文对话示例
```
1. 用户：查询一班的学生
   系统：显示一班所有学生

2. 用户：其中男生多少？
   系统：基于上一次查询结果，统计一班中的男生人数
```

## 🔧 模块说明

### `student_model.py`
- **Student 类**：学生数据模型
- **StudentManager 类**：学生数据管理，包括加载、保存、增删改查等操作

### `gui_interface.py`
- **StudentManagementGUI 类**：图形界面主类
- 实现所有界面操作和交互逻辑

### `natural_language.py`
- **NaturalLanguageProcessor 类**：自然语言处理器
- 解析中文指令，提取操作类型和参数

### `statistics.py`
- **StatisticsAnalyzer 类**：统计分析器
  - 生成统计报告
  - 按条件统计人数
- **NaiveBayesPredictor 类**：朴素贝叶斯预测器
  - 基于历史数据训练模型
  - 预测学生班级

### `validator.py`
- **Validator 类**：数据验证器
- 验证学号唯一性、年龄范围、电话格式、班级格式等

### `dialog_context.py`
- **DialogContext 类**：对话上下文管理器
- 支持多轮对话和上下文关联

## 📝 数据格式

### 学生数据结构
```json
{
  "student_id": "2023001",
  "name": "张三",
  "age": 18,
  "gender": "男",
  "class_name": "一班",
  "phone": "13812345678"
}
```

### 数据验证规则
- **学号**：不能为空，必须唯一
- **姓名**：不能为空，不超过20字符
- **年龄**：10-22岁之间的整数
- **性别**：只能是"男"或"女"
- **班级**：格式为"X班"（如：一班、1班）
- **电话**：11位数字，以1开头

## 🐛 常见问题

### Q: 程序无法启动？
A: 确保已安装 Python 3.6+，并且 tkinter 模块可用（通常已包含在 Python 标准库中）。

### Q: 数据丢失了怎么办？
A: 所有数据自动保存到 `students.json` 文件中。如果文件损坏，可以手动编辑 JSON 文件或删除后重新添加。

### Q: 自然语言指令无法识别？
A: 请参考上面的示例格式，使用标准的中文表达。系统支持多种同义词（如：添加/新增/创建）。

### Q: 预测结果不准确？
A: 预测模型的准确性取决于训练数据的数量和分布。添加更多学生数据后，预测会更准确。
