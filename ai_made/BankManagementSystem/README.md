一个写完后端程序之后，尝试用deepseek完成的，利用tkinter实现GUI界面的期末作业————银行管理系统。

基于 Python 和 Tkinter 开发的银行管理系统，提供图形化用户界面，支持管理员和客户两种角色。

## ✨ 功能特性

### 客户功能
- ✅ **开户** - 创建新的银行账户
- ✅ **查询余额** - 查看账户余额和基本信息
- ✅ **取款** - 从账户中取款
- ✅ **存款** - 向账户中存款
- ✅ **转账** - 向其他账户转账
- ✅ **锁定账户** - 锁定自己的账户（需要密码验证）
- ✅ **交易记录** - 查看交易历史

### 管理员功能
- ✅ **开户** - 为客户创建新账户
- ✅ **锁定账户** - 锁定指定账户
- ✅ **解锁账户** - 解锁被锁定的账户
- ✅ **查看所有账户** - 显示系统中所有账户信息

### 安全特性
- 🔒 密码验证机制
- 🔒 账户锁定功能（密码错误3次自动锁定）
- 🔒 管理员登录验证
- 🔒 交易记录日志

## 📖 使用说明

### 启动流程

1. **运行程序** → 打开登录界面
2. **输入管理员账户和密码** → 点击"登录"
3. **选择角色** → 选择"管理员功能"或"客户功能"
4. **使用相应功能** → 根据角色执行相应操作

### 客户功能使用

1. **开户**
   - 点击"开户"按钮或使用菜单栏
   - 填写个人信息（姓名、身份证号、手机号、预存金额、密码）
   - 系统自动生成6位卡号
   - ⚠️ **重要**: 请妥善保管卡号和密码！

2. **查询余额**
   - 输入卡号和密码
   - 查看账户余额和基本信息

3. **取款/存款**
   - 输入卡号和密码验证
   - 输入金额并确认
   - 系统自动更新余额

4. **转账**
   - 输入转出卡号和密码
   - 输入转入卡号
   - 输入转账金额并确认

5. **锁定账户**
   - 输入卡号和密码
   - 确认锁定操作
   - 锁定后无法进行任何操作，需管理员解锁

### 管理员功能使用

1. **开户** - 为客户创建新账户
2. **锁定/解锁账户** - 管理账户状态
3. **查看所有账户** - 显示系统中所有账户的详细信息

### 快捷键

- `Ctrl+N` - 快速开户（客户界面）
- `Ctrl+Q` - 快速退出系统

## 🔍 功能详解

### 数据存储

- **账户信息**: 存储在 `bank_data.txt` 中，使用 JSON 格式
- **交易记录**: 记录在 `transaction_log.txt` 中
- **数据格式**:
  ```json
  {
    "账户信息": {
      "卡号": {
        "姓名": "...",
        "身份证号": "...",
        "手机号": ...,
        "金额": ...,
        "密码": "..."
      }
    },
    "锁定账户信息": {
      "卡号": {...}
    }
  }
  ```

### 安全机制

1. **密码验证**: 所有操作都需要密码验证
2. **自动锁定**: 密码错误3次自动锁定账户
3. **账户状态检查**: 锁定账户无法进行任何操作
4. **管理员验证**: 管理员操作需要登录验证

### 卡号生成

- 系统自动生成6位数字卡号（100000-999999）
- 确保卡号唯一性

## ⚠️ 注意事项

1. **数据安全**
   - `bank_data.txt` 包含所有账户信息，请妥善保管
   - 建议定期备份数据文件
   - 生产环境请使用加密存储

2. **密码管理**
   - 默认管理员密码为 `12345`，请及时修改
   - 客户密码以明文存储，生产环境请使用加密

3. **账户锁定**
   - 密码错误3次会自动锁定账户
   - 锁定后需管理员解锁才能继续使用

4. **数据持久化**
   - 所有操作都会自动保存到文件
   - 请勿手动修改 `bank_data.txt` 文件格式

5. **系统兼容性**
   - 支持 Windows、macOS、Linux
   - 需要系统支持 Tkinter GUI

3. **更新菜单和按钮绑定**

### 代码结构

- **业务逻辑层**: `bank_main.py` - 所有业务操作
- **表示层**: `customer_gui.py`, `admin_simple.py` - GUI界面
- **控制层**: `bank_gui.py`, `role_selector.py` - 流程控制
